# Code of Conduct

We want this project to be a respectful, practical place to collaborate.

## Expected behavior

- Be constructive and specific.
- Respect different experiences and viewpoints.
- Focus criticism on ideas and code, not people.
- Protect the privacy of users and never request unredacted AI logs.

## Unacceptable behavior

Harassment, discrimination, personal attacks, doxxing, publishing private logs, or other conduct that makes participation unsafe is not acceptable.

Project maintainers may edit, remove, or reject contributions and interactions that violate these expectations.

## Reporting

For ordinary moderation concerns, contact the maintainers through the repository. For security or privacy vulnerabilities, follow [SECURITY.md](./SECURITY.md).
