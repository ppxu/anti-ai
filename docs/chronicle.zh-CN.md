# 异变年鉴

异变年鉴把现有的本地异变体档案整理成一份紧凑的纵向标本记录。它是收藏与展示层，不是新的成长循环。

```bash
anti-ai creature chronicle
anti-ai creature chronicle --date 2026-08-08 --lang zh
anti-ai creature chronicle --json
anti-ai share --card dossier > anti-ai-dossier.svg
```

以上命令都只读。为了生成首次运行或尚未结算日期的当前快照，显式 CLI 命令可能像 `codex` 一样扫描受支持的用量元数据，但不会读取对话正文，也不会保存内存中的派生结果。它们不会结算日期、创建存档、消耗操作次数或改变收藏概率。

## 当前档案

年鉴使用稳定的本地标本编号和派生外观指纹识别当前异变体，并汇总：

- 世代、世代日、生命阶段、病型、生态人格和当前形态；
- 当前主导常规能力与称号；
- 已绑定伴生物的阶段和路线；
- 针对所选日期确定性生成的讽刺诊断；
- 档案中最近一次有日期的结构变化或收藏变化。

诊断只根据异变体 seed、日期和生态人格，从固定双语语料中本地选择，不会调用模型。

## 7、30 与 90 天病程

三个窗口都以所选日期为终点，使用现有病例簿中的隐私安全字段派生：

- 已观察日、活跃日和 AI 清醒日；
- 主要症状；
- 污染与清醒变化；
- 阶段和世代成长；
- 新发现与已完成远征；
- 主导能力或伴生物阶段变化。

人类输出保持紧凑；`--json` 提供完整派生结构，但仍不包含精确 Token、请求数、模型/来源名、本地路径、Prompt、回复或逐请求时间。

## 世代对照

当前世代优先与最近一份上一代永久化石比较；尚未产生上一代化石时，则使用第一次活跃孵化日期作为起点。

对照内容包括可见形态身份、主导能力、污染/清醒差值和能力总值差。它只是回顾记录，不是预测、分数、战力或优化目标。

## 病理星图

十二组只影响展示的星座完全从图鉴已有发现派生。污染、清醒、悖论三条路线各有一组稀有征象、两组史诗症候群，以及一组初始隐藏的传奇复合诊断。

| 路线 | 稀有度 | 星座 | 宽泛证据 |
| --- | --- | --- | --- |
| 污染 | 稀有 | 持证暴食 | 污染形态、罪证章、污染生态现象、反应堆墓场遗物 |
| 污染 | 史诗 | 缓存来世 | 缓存形态、缓存罪证、缓存沼泽遗物、缓存培养物 |
| 污染 | 史诗 | 请求供应链 | 请求形态、请求罪证、请求巢遗物、请求培养物 |
| 污染 | 传奇 | 核准崩坏 | 三份污染诊断与碳化伤痕 |
| 清醒 | 稀有 | 人工接管 | 清醒形态、戒断章、清醒生态现象 |
| 清醒 | 史诗 | 安静遗传 | 清醒伤痕、清醒病例、清醒伴生物、远征负向微调 |
| 清醒 | 史诗 | 低功耗赦免 | 戒断章、清醒现象、清醒病例、清醒培养物 |
| 清醒 | 传奇 | 零瓦封圣 | 三份清醒诊断与无菌伤痕 |

| 悖论 | 史诗 | 双重监护 | 悖论证据、分裂继承、共振培养物、正负同舱返航 |
| 悖论 | 传奇 | 双边现实故障 | 三份悖论诊断与分裂阴影伤痕 |

每组星座都有四段确定性双语病程：未知、起病、近成与确诊。同一路线完成两份诊断后，传奇星座才会显露名称与精确条件；在此之前，人类输出只展示宽泛证据域。运行 `anti-ai codex --set <set-id>` 可以查看聚焦终端视图，JSON 则返回语言无关的聚焦对象。

完成星座只会揭示印章和展示语料，不增加能力点、阅历、远征次数、稀有概率、每日操作或成长速度。固定图鉴分母仍为 134 项，这十二组派生诊断不计入分母。

## 馆藏诱发异变

固定图鉴发现只会在四个刻意拉长的里程碑改变本体展示：

| 阶段 | 固定发现 | 类目广度 |
| --- | ---: | ---: |
| I | 34 / 134 | 3 / 7 |
| II | 67 / 134 | 5 / 7 |
| III | 101 / 134 | 6 / 7 |
| IV | 134 / 134 | 7 / 7 |

跨过里程碑的那项发现会从七类稳定证据母题中确定一种；结合四个阶段，共形成 28 种馆藏异变，另有一组原始形态。它完全根据带日期的固定发现即时重算，可在异变体、年鉴、生态舱、TUI 和档案/生态舱卡片上增加冠层或外骨骼，但不会改变数值、基础外观指纹、污染码、收藏概率或持久化状态。

## TUI 与分享

TUI 仍保留原有五个区域。总览增加紧凑的年鉴面板，图鉴则把三条路线组织成病理星图，并可聚焦查看证据与病程阶段。TUI 只使用已经加载的异变体状态，不会为这些投影扫描 Agent 记录。星座不能放入后果陈列柜，因为它们是展示组合，而不是独立收藏物。

总览分享现在会准备“异变档案”卡。1200×630 SVG 包含异变体剪影、可选伴生物、当前诊断、30 天病程、世代对照和已完成套组印章。卡片完全在本地生成，遵循既有的预览、明确确认、备用目录和禁止覆盖规则。

## 状态与隐私

异变体档案继续使用 schema v14。年鉴、星座进度、传奇显露与馆藏异变都会针对所选历史日期即时重算，不写入 `~/.anti-ai/creature.json`。

历史视图不会带入之后才发生的发现与远征结果。公开年鉴 JSON 和档案 SVG 不包含精确 Token、请求数、模型或 Agent 名称、Prompt、回复、工具调用、本地路径、逐请求时间、内部计划哈希或尚未开启的远征事件。
