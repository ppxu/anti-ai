# 成长外观图鉴

[English](./creature-growth-appearance.md) | 简体中文 · [基础器官图鉴](./creature-organs.zh-CN.md) · [异变体成长指南](./creature.zh-CN.md)

除 40 个结构性器官外，核能巨兽生成器目前还使用 **24 个可见成长元素**：

```text
4 生态人格标记 + 4 使用病型头冠
+ 6 普通纹路 + 4 世代伤疤 + 3 成就印记 + 3 异色覆盖层
= 24 个源码元素
```

这 24 个元素并不占用同一个位置。最终形态会分别选择一种生态人格、一种使用病型，再从 16 个互斥胸腔覆盖层中选择一种：

```text
4 生态人格 × 4 使用病型
×（6 普通纹路 + 4 伤疤 + 3 成就印记 + 3 异色覆盖层）
= 256 种成长外观
```

下面展示的是当前 [`src/creature.mjs`](../src/creature.mjs) 渲染器实际使用的字符。

## 位置与显现阶段

```text
                  使用病型头冠
                        ↓
              ╭─────────────────╮
              │     核能巨兽    │
              │ 生态标记  胸腔  │
              │          覆盖层 │
              ╰─────────────────╯
```

| 外观层 | 显现方式 |
|---|---|
| 生态人格 | 所有阶段都会决定整只标本的颜色；早期占用胸腔位置，可能被伤疤替换；完全体拥有独立的身体标记位置。 |
| 使用病型 | 从阶段 II 开始改变头冠；阶段 I 使用固定的胚体头冠。 |
| 胸腔覆盖层 | 根据阶段和优先级，在异色、成就、伤疤或普通纹路中显示一种。 |

## 生态人格标记 · 4

生态人格由长期污染性与清醒性共同塑造。完全体会在胸腔覆盖层旁边保留该标记。

| 生态 ID | 含义 | 图形 | 终端颜色 |
|---|---|:---:|---|
| `unformed` | 两条轴都尚未形成稳定身份 | `·····` | 暗色 |
| `polluted` | 污染性占优 | `!!~!!` | 红色 |
| `lucid` | 清醒性占优 | `--○--` | 青色 |
| `paradox` | 污染性与清醒性都高度发育 | `!X!X!` | 品红 |

## 使用病型头冠 · 4

使用病型由 Coding Agent 的主要使用方式决定。

| 病型 ID | 分支 | 图形 |
|---|---|:---:|
| `context` | 上下文病变系 | `╱╲[[ ]]╱╲` |
| `cache` | 缓存化石系 | `▟▙▟▙▟▙` |
| `frenzy` | 请求增殖系 | `╱◉╲╱◉╲╱◉╲` |
| `nuclear` | 核食系 | 阶段 II `╱╲╱╲` · 阶段 III `╱╲╱╲╱╲` · 阶段 IV `╱╲╱╲╱╲╱╲` |

## 普通基因纹路 · 6

这些稳定的本地基因会在完全体显现；存在更高优先级覆盖层时不会展示。

| 纹路 ID | 图形 |
|---|:---:|
| `pattern_01` | `. . .` |
| `pattern_02` | `x-x-x` |
| `pattern_03` | `:::::` |
| `pattern_04` | `+-+-+` |
| `pattern_05` | `[=*=]` |
| `pattern_06` | `o-o-o` |

## 世代继承伤疤 · 4

一个 90 天世代结束时，其最终生态人格会决定下一代继承的伤疤。

| 伤疤 ID | 来源生态 | 图形 |
|---|---|:---:|
| `blank_suture` | 未定型 | `--//--` |
| `carbonized_spine` | 污染型 | `##/##` |
| `sterile_halo` | 清醒型 | `oo/oo` |
| `split_shadow` | 矛盾型 | `//\\//` |

## 成就印记 · 3

24 个成就 ID 会按类型归并为三类可见印记；完全体使用最近解锁成就所属的类型。

| 类型 | 成就 ID 数 | 图形 |
|---|---:|:---:|
| `offense` / 罪证 | 8 | `!!x!!` |
| `sobriety` / 戒断 | 8 | `--X--` |
| `paradox` / 悖论 | 8 | `!X?X!` |

## 异色覆盖层 · 3

6 种异色能力会按稀有度归并为三档外观。觉醒后会改变整只标本的颜色，并替换低优先级胸腔标记。

| 稀有度 | 能力数 | 图形 | 终端颜色 |
|---|---:|:---:|---|
| R / `rare` | 3 | `@R@R@` | 青色 |
| SR / `epic` | 2 | `@S@S@` | 品红 |
| SSR / `mythic` | 1 | `@X@X@` | 黄色 |

## 胸腔覆盖优先级

最终形态只会从 16 个互斥选项中显示一套胸腔覆盖层：

```text
异色覆盖层
    ↓ 覆盖
成就印记
    ↓ 覆盖
世代伤疤
    ↓ 覆盖
普通基因纹路
```

阶段 I–III 不显示普通基因纹路和成就印记。此时如果已经觉醒异色能力则显示异色覆盖层，否则优先显示继承伤疤，没有伤疤时显示当前生态标记。阶段 IV 会把生态标记移入独立位置，再按照上面的顺序结算胸腔覆盖层。

具体的异色能力等级、同类型下的成就 ID、称号、心情和成长数值仍会出现在病历或 JSON 中，但不会继续增加 ASCII 几何形态。
