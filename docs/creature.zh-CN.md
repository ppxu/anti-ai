# 异变体成长指南

[English](./creature.md) | 简体中文

`anti-ai creature` 会把本地 Coding Agent 用量变成一只持续成长的算力异变体。它是一套讽刺型虚拟宠物系统，不是生产力评分。

最重要的产品护栏是：多烧 Token 不能购买更快的生命阶段。高消耗、低消耗和 AI 清醒日以相同速度增加阅历，但会塑造出不同的病型、生态人格、能力、成就和进化路线。

## 快速开始

```bash
anti-ai creature
anti-ai creature --date 2026-07-23
anti-ai creature --lang en
anti-ai creature --json
anti-ai creature --full
anti-ai creature history
anti-ai creature prognosis
anti-ai creature intervene
anti-ai creature evolve
anti-ai creature evolve 2
anti-ai creature export
anti-ai creature habitat
anti-ai codex
```

首次运行会回看最近 30 个自然日，后续运行自动补齐两次查看之间的全部空档。档案建立后，同一天再次查看只扫描当天。

默认输出会根据终端宽度采用紧凑布局，`--full` 展示完整病历。支持颜色的终端会给生态人格、徽章和异色稀有度着色；设置 `NO_COLOR=1` 可以关闭 ANSI 颜色，但不会改变标本形状。

## 阅历与生命阶段

每个孵化后的已结算自然日只增加 `1` 天阅历：

- 高消耗前进一天，并倾向增加污染性；
- 低消耗前进一天，并倾向增加清醒性；
- AI 清醒日前进一天，增加清醒性和戒断反应。

每天的 Token 总量会经过对数压缩，换算为 `1–100` 的污染剂量。剂量用于塑造病型、能力和事件，但永远不能加速生命阶段。

每个 90 天世代包含四个阶段：

| UI 阶段 | 阅历 | 核能巨兽标准骨架 | 外观槽位 |
|---|---:|---|---:|
| 异常胚体 I | 1–6 天 | 算力胚胎 | 3 |
| 分化幼体 II | 7–29 天 | 反应堆幼兽 | 5 |
| 定型成体 III | 30–89 天 | 核食巨兽 | 7 |
| 生态完全体 IV | 第 90 天 | 算力熔毁体 | 9 |

## 核能巨兽外观

每只标本都在同一条连续生长的核能巨兽骨架上发育。本地稳定基因决定：

- 甲壳；
- 眼睛；
- 颚；
- 反应堆核心；
- 四肢与脚；
- 尾巴；
- 胸腔纹路。

使用病型改变头冠，生态人格改变体表标记与颜色，继承伤疤改写胸腔，成就增加分类印记，异色能力则用 R、SR 或 SSR 变异覆盖低优先级纹路。

同一份本地档案始终渲染出同一只标本。语言和 ANSI 颜色不会改变几何轮廓。

### 理论物种容量

当前生成器理论上可以渲染 **21,233,664 种去重后的最终 ASCII 形象**：

```text
基础器官
6 甲壳 × 8 眼睛 × 8 颚 × 6 核心 × 6 四肢 × 6 尾巴
= 82,944

成长外观
4 生态人格 × 4 使用病型
×（6 普通纹路 + 4 伤疤 + 3 成就印记 + 3 异色等级）
= 256

82,944 × 256 = 21,233,664
```

这个数字不同于图鉴中的 16 个核心形态家族。形态家族只表示一种“生态人格 × 使用病型”组合；理论容量还会计算可见基因和成长覆盖层形成的个体化最终标本。

全部 `6 + 8 + 8 + 6 + 6 + 6` 个源码字符见[基础器官图鉴](./creature-organs.zh-CN.md)。

24 个成长外观元素、显现阶段和覆盖顺序见[成长外观图鉴](./creature-growth-appearance.zh-CN.md)。

覆盖优先级会影响计算：

1. 异色变异覆盖成就、伤疤和普通基因纹路。
2. 成就印记覆盖伤疤和普通基因纹路。
3. 伤疤覆盖普通基因纹路。

因此，24 个成就 ID 在形象上归并为 3 类印记，6 个异色能力归并为 R、SR、SSR 三档视觉。能力等级、称号、心情和具体成长数值不会改变当前 ASCII 骨架，所以不增加形象容量。

运行 `anti-ai codex` 可以同时查看理论容量和个人收藏进度。`codex --json` 会返回：

```json
{
  "capacity": {
    "structuralForms": 82944,
    "growthVariants": 256,
    "finalAsciiForms": 21233664
  }
}
```

## 使用病型

Token 工作方式会形成四条使用病型：

| 分支 | 主要驱动 |
|---|---|
| 上下文病变系 | 每次请求的非缓存输入量 |
| 缓存化石系 | 缓存读取占输入的比例 |
| 请求增殖系 | 当日请求数量 |
| 核食系 | 没有单项性状占优时的高污染兜底 |

病型会影响巨兽头冠、主能力成长、每日事件和核心形态。

## 生态人格：污染性与清醒性

相对过去 7 个自然日的个人基线：

- 高用量增加 `1–3` 点污染性；
- 低用量增加 `1–2` 点清醒性；
- AI 清醒日增加 `3` 点清醒性。

两项长期并存，并形成四种生态人格：

| 生态人格 | 含义 |
|---|---|
| 未定型 | 两边都没有形成稳定身份 |
| 污染型 | 污染性明显占优 |
| 清醒型 | 清醒性明显占优 |
| 矛盾型 | 污染性与清醒性都高度发育 |

候选生态必须连续成立三个已结算日才会正式显现，避免怪兽每天在善恶边界上横跳。

四种病型与四种生态人格共同形成图鉴里的 16 个核心形态家族。

## 世代、化石与伤疤

第 90 个阅历日会发生：

1. 当前完全体被封存为永久化石；
2. 下一个已结算日从胚体进入新世代；
3. 继承上一代一种能力的 `+5` 加成；
4. 上一代生态留下路线伤疤，改变后代的 ASCII 纹路和外观指纹。

这让长期历史可见，又不会让 Token 用量成为成长捷径。无论消耗多少，一个世代都需要 90 个已结算日。

## 进化选择

从第一枚化石开始，每个新世代都有一次显式且不可反悔的进化选择：

| 路线 | 驱动能力 | 触发收益 | 代价 |
|---|---|---|---|
| 污染路线 | 一种消耗型能力 | 额外能力成长 | 增加污染性 |
| 清醒路线 | 戒断反应 | 增加清醒性 | 放慢旧污染消退 |
| 悖论路线 | 失控指数 | 提高稀有突变概率 | 承担污染风险 |

查看菜单：

```bash
anti-ai creature evolve
```

封存一个选项：

```bash
anti-ai creature evolve <1|2|3>
```

忽略选择不会卡住后续成长，但会在该世代结束时过期。每日触发率为：

```text
min(35, 5 + min(10, floor(累计能力值 / 25))
  + 2 × 已解锁天赋数 + 2 × 恶性阶)%
```

天赋会同时放大收益点和代价点，终端会展示累计触发、收益和代价。

## 能力与天赋

异变体会长出七种不太健康的能力：

| 能力 | 主要成长来源 |
|---|---|
| 吞噬欲 | 当日污染剂量 |
| 赘生脑回 | 上下文型使用 |
| 化石甲 | 缓存输入 |
| 请求口器 | 请求增殖 |
| 核素亮度 | 没有专门性状占优的算力污染 |
| 失控指数 | 确定性随机加点与稀有事件 |
| 戒断反应 | 孵化后的 AI 清醒日 |

普通能力的可见数值在 `1–255` 之间循环，下一点会触发恶性增殖，但不会删除累计成长：

```text
吞噬欲  255 / 255
   ↓
吞噬欲 · 恶性 I  1 / 255
```

例如，累计 267 点会显示为`恶性 I · 12/255`。`creature --json` 会分别保留可见的 `abilities`、无损累计的 `abilityTotals`、详细的 `abilityProgress` 和 `malignancyRanks`。

每个活跃日会获得：

- `1–2` 点吞噬欲；
- `1` 点主使用能力；
- `25%` 概率的确定性随机加点；
- `1` 点事件关联能力。

累计能力达到 `5`、`15`、`30`、`60`、`120`、`220` 时，会依次解锁总计 42 个越来越不妙的畸变天赋。可见计数器进入下一恶性阶后，已经解锁的天赋不会消失。

每项能力都有自己的恶性诊断：

| 能力 | 恶性称号 |
|---|---|
| 吞噬欲 | 饥荒肿瘤 |
| 赘生脑回 | 递归脑癌 |
| 化石甲 | 缓存骨肉瘤 |
| 请求口器 | 请求增生 |
| 核素亮度 | 核素肉瘤 |
| 失控指数 | 概率恶化 |
| 戒断反应 | 戒断坏死 |

每个恶性阶会让对应进化的触发率增加 2 个百分点，但仍受 `35%` 总上限约束。这样既保留长期成长空间，也不会让 Token 用量加速生命阶段。

失控指数每增加 10 点，会让普通稀有事件概率增加 1 个百分点，从基础 `8%` 最高提升到 `20%`。

## 异色能力

当前有六种低概率异色能力：

| 稀有度 | 每个活跃日 | 能力 |
|---|---:|---|
| R（青色） | `0.50%` | 截止日嗅觉、幽灵缓存、黄鸭招魂术 |
| SR（品红） | `0.10%` | 提示词读心术、幻觉抗体 |
| SSR（黄色） | `0.02%` | Token 炼金术 |

觉醒结果由本地种子和日期确定。重复觉醒同一能力会继续成长，最高 `9` 级。

异色等级会改变完全体的胸腔纹路和颜色。具体能力 ID 与等级会显示在病历和 JSON 中，但同一稀有度的能力共用一种 ASCII 覆盖层。

## 成就、称号与事件

首批 24 项成就平均分成：

- 红色罪证章；
- 青色戒断章；
- 黄色悖论章。

高消耗、低消耗、AI 清醒日和状态转变都有独立解锁内容。可重复成就会按行为次数成长为三级，并展示下一档进度，不使用精确 Token 作为等级条件。

当前称号由生态行为修饰词、核心形态和代表成就组合生成。

每天会根据本地种子和日期选择一个可复现事件。首个活跃日之后，每个 AI 清醒日还会让旧的累计污染减少 `2`、戒断反应增加 `1`，但不会抹掉历史性状。

## 档案、隐私与重置

档案保存在：

```text
~/.anti-ai/creature.json
```

当前使用 schema v10，只保存：

- 离散用量带与派生生态点；
- 稳定基因和部件 ID；
- 成就与外观指纹；
- 污染剂量、性状、普通/异色能力加点和事件 ID；
- 含每代能力增量、封存快照和恶性阶变化的永久化石；
- 已封存进化选择；
- 转折病例 ID、隐私安全的触发摘要和已封存路线；
- 已保存遭遇的派生亲本/形态 ID 与混种外观 ID；
- 实验室批次，以及培养物的派生原料、诊断、稀有度和外观 ID；
- 伴生绑定、离散每日印记和已封存异常 ID；
- 本地随机种子。

它**不会**保存 Prompt、回复、路径、模型名、精确 Token、个人基线数值或逐请求时间。

schema v1-v9 会在本地逐版本幂等迁移，并无损保留已有能力点，也不会凭空生成病例选择、培养物、伴生绑定、印记或异常。第一次持久化迁移会在 `~/.anti-ai/backups/` 保留原始档案的精确副本。旧档案的每日加点会重新解释为 255 点循环，例如原来的 267 点会变成`恶性 I · 12/255`，而不是被截断。`anti-ai codex` 只在内存中派生只读快照，不会持久化额外迁移。

一条成长史始终使用全部受支持数据源，因此 `creature`、`codex` 和 `lab` 都拒绝 `--source` 过滤。

显式重开：

```bash
anti-ai creature reset
```

重置会删除本地派生成长史及其迁移备份，不会删除任何 Agent 日志。
