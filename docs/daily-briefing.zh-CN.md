# 每日收容播报

[English](./daily-briefing.md)

每日收容播报把总览收束成回答四个问题的唯一入口：今天封存了什么、发生了什么变化、生态舱如何反应，以及现在是否值得做一项操作。

## 打开方式

```bash
anti-ai tui
anti-ai tui --lang zh
anti-ai tui --no-motion
```

总览默认进入播报模式。它不是开屏弹窗，也不记录“已读”：`1`–`5` 可以立即切换到其他区域。按 `e` 展开或收起完整标本档案，按 `a` 打开完整行动中心，按 `s` 预览每日 SVG 封面。

## 播报顺序

结构化投影始终按以下顺序提供五段信息：

1. **系统状态**：日期是否已经结算，以及宽泛的使用/生态摘要；
2. **当前诊断**：复用现有确定性异变年鉴诊断；
3. **关键变化**：依次从孵化/病理变化、收藏、本地记录、生态漂移或无显著变化中选择第一项；
4. **收藏更新**：单独展示数量，避免把收藏事件和叙事文案混在一起；
5. **生态舱反应**：复用现有确定性的活体生态舱场景与短讯。

播报最多推荐一个既有操作。`Enter` 使用与完整行动中心相同的动作服务和确认规则处理它。播报不会制造另一项行动、奖励、稀有率抽取或每日机会。

## 完整档案

按 `e` 后可以查看此前直接展示在总览中的完整信息：当前标本与病理、世代进度、下一里程碑、7/30/90 天年鉴、世代对照、病理星图进度和最多两项可用行动摘要。展示模式只存在于当前 TUI 会话，不会写入存档。

## 分享播报

```bash
anti-ai share --card briefing > anti-ai-briefing.svg
anti-ai share --card briefing --date 2026-07-23 --lang zh > anti-ai-briefing.svg
```

1200×630 卡片与 TUI 总览使用同一份播报投影。显式 CLI 导出可以只在内存中推导所选日期，但不会持久化这次结算。卡片不包含精确 Token、请求数、模型/来源名、Prompt、回复、工具调用、路径、逐请求时间或内部哈希。`dossier` 继续作为独立的长期年鉴卡。

## 状态与成长边界

打开、展开、导航和预览播报都只读，不增加 Creature schema 字段，也不会扫描 Agent 日志。只有明确打开“今日结算”的影响预览时才可能扫描受支持的用量元数据，且只有显式确认才会通过现有原子状态服务写入。高消耗、克制使用和 AI 清醒日继续按原有等速路线成长。
