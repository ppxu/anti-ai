# 本地异变体遭遇

[English](./encounters.md)

`anti-ai` 遭遇系统让两只独立成长的异变体在没有服务器、没有共享用量数据库的前提下，生成一次确定性的本地事故。

## 快速开始

在一台机器上：

```bash
anti-ai creature export
```

只发送生成的 `AA1...` 污染编码。在另一台机器上：

```bash
anti-ai encounter <污染编码>
anti-ai encounter <污染编码> --save
anti-ai share --card encounter --with <污染编码> > encounter.svg
```

人类输出可使用 `--lang en` 或 `--lang zh`；稳定 ID 使用 `--json`。

## 遭遇如何生成

一次遭遇会混合两份外观快照：

- 稳定器官基因；
- 当前生命阶段、生态人格和使用病型；
- 当前可见成就、异色能力和遗传伤痕；
- 公开标本编号与外观指纹。

混合前会先排序双方指纹，因此同一对标本无论谁发起，事故编号和混种结果都一致。亲本基因通过固定规则选择。污染型与清醒型相遇会产生矛盾型混种；其他生态与病型组合也只使用本地固定规则。

算力天气由所选自然日派生，只负责增加气氛，不依赖网络随机数。同一亲本、同一日期重复运行，会得到完全相同的结果。

## 可选收藏

遭遇默认不会收藏混种。添加 `--save` 后，才会把一条派生记录放进 `anti-ai codex` 的外来标本柜。和查看 `creature` 一样，遭遇前会先正常结算本地异变体到所选日期的成长史。

保存是幂等的：同一次事故不会制造重复库存。记录只包含事故、日期、类型、天气 ID，亲本标本/形态 ID，以及混种外观快照；不会改变异变体阅历、能力、生态、成就或进化。

## 污染编码协议

版本 1 的格式是：

```text
AA1.<base64url JSON 载荷>.<10 字符校验值>
```

载荷只包含离散外观 ID。校验值可以发现截断和普通篡改，但它不是数字签名，不能证明编码由谁生成。应把污染编码视为公开且不可信的收藏品。

解析器会：

- 拒绝未知协议版本；
- 把输入限制在 2,048 个字符；
- 在解析前校验完整性；
- 校验每一个标本、基因、形态、成就、异色能力和伤痕 ID；
- 拒绝自己与自己发生遭遇。

## 隐私边界

污染编码和遭遇分享卡都不包含：

- 精确 Token 与请求数；
- 模型与 Agent 来源名；
- Prompt、回复和工具调用；
- 文件、项目和会话路径；
- 请求时间与个人基线。

`export`、`encounter`、`--save` 和 SVG 渲染全部在本地完成，不会上传数据。

这个玩法刻意不提供 Token 排行榜、战力、胜负或服务端稀有交易。高消耗、低消耗和 AI 清醒日仍会塑造不同的怪兽，但多烧 Token 不会成为唯一升级捷径。
