# 收容远征

收容远征是异变体的一套小型纯本地探索循环。一局没有地图、战斗、生命值、装备、货币、体力、队伍、排行榜或在线服务：选择一个目的地，依次揭示十格，再把结果封存为病例记录。

## 每日机会

- 每个本地自然日最多提供一次远征机会，即使当天尚未结算进异变体成长史也可以开启。
- 机会不累计。跳过没有惩罚，但档案进入更新的结算日期或远征日期后，不能再回头补用旧日期。
- 开始远征时立即消耗该本地日期的机会。
- 退出只会暂停，之后可以继续同一局。
- 隔天完成或放弃一局旧远征不会消耗新日期的机会。放弃会封存已经到达的格子，且不能借此重抽目的地或事件序列。
- 高消耗、克制使用和 AI 清醒日以相同速度获得机会；Token 量不会增加局数、格数、稀有度、遗物概率或成就进度。

## 目的地

| ID | 目的地 | 环境病症 |
| --- | --- | --- |
| `context_mine` | 上下文矿井 | 被压缩、截断和递归引用的地下记忆层 |
| `cache_swamp` | 缓存沼泽 | 过期答案沉积成仍然自信的缓存命中 |
| `request_nest` | 请求巢穴 | 排队、重试并自我复制的请求口器 |
| `reactor_graveyard` | 反应堆墓场 | 余热、算力灰和回答结束后仍在工作的风扇 |

目的地会改变文案、分叉选择和对应的 6 件遗物，但不存在更强或更高效的路线。

## 十格流程

每局会封存一套事件牌组：

- 2 格无事发生；
- 2 格环境观察；
- 2 格临时病变；
- 1 格永久能力微调；
- 1 格三选一处置分叉；
- 2 格通配事件，可能成为遗物、异常、空白、观察；绑定伴生物后也可能触发伴生介入。

事件顺序由本地异变体种子、远征序号、目的地、世代和远征内容版本共同派生。日期、语言、终端宽度、动态设置、重复查看和 Token 量都不能重抽。公开 CLI、TUI 与 JSON 不会暴露内部计划种子和尚未揭示的事件序列。

临时病变只在本局生效。完整远征最多遇到一次永久能力微调：通常为 `+1` 或 `-1`；1% 的命名副作用会变成 `+2` 或 `-2`，能力不会降到零以下。分叉可临时增加 `-2`、`0` 或 `+2`，必须封存选择后才能进入下一格。

## 事件与返航展示

人类 CLI、TUI 与远征分享卡共用同一套展示模型。每个已揭示格都有明确标签：静默格、普通事件、状态变动或特殊事件，避免把事件叙事误认成系统提示。TUI 会把系统封存记录单独放在一行，并保留最近三格的紧凑轨迹。

完成或放弃后的记录会派生一份确定性返航总结：行程与事件计数、特殊事件和状态变动数量、带稀有度的遗物、成就、永久后遗症、返航时失效的临时状态、最近三格，以及一条讽刺诊断。总结只在读取时派生，不增加存档字段或奖励。

## 命令

```bash
anti-ai expedition
anti-ai expedition --json
anti-ai expedition start context_mine
anti-ai expedition next
anti-ai expedition choose <1|2|3>
anti-ai expedition history
anti-ai expedition abandon
anti-ai share --card expedition > anti-ai-expedition.svg
```

运行 `anti-ai help expedition` 或 `anti-ai help expedition <action>` 查看聚焦的双语 Help。状态、历史和分享只读；开始、推进、选择与放弃只会在命令成功后写入。查看历史日期时，状态、历史和分享不会泄露后来发生的远征或发现。状态 JSON 会提供请求的 `date` 和最近一次启程日期 `lastStartedDate`；已有阅历日字段继续作为历史上下文保留，不再决定每日资格。

## TUI 操作

远征是控制台五个区域中的第 3 个，按 `3` 进入。

- `↑` / `↓`：开始前选择目的地；
- `Enter`：直接从当前目的地启程、推进一个普通格，或封存当前分叉选择；
- `1`–`3`：出现分叉时选择一项处置；
- `x`：预览放弃当前远征；
- `q`：离开远征区域，保留当前进度；
- `s`：预览本地远征 SVG；
- `m`：切换全局低频动态档位。

所有写入都经过共享应用动作服务和原子状态存储。远征启程、普通推进与分叉处置把当前目的地或选项加 `Enter` 视为明确确认；在刷新快照返回前，输入锁会忽略重复按键。放弃远征仍保留独立的预览确认步骤。TUI 不会调用 CLI 命令处理器或 Shell。

## 收藏

固定图鉴从 98 项扩展到 134 项：

- 24 件远征遗物：每个目的地 6 件，分别为 2 件 Common、2 件 Uncommon、1 件 Rare 和 1 件 Epic；
- 12 项远征成就：覆盖首次返航、空手返航、封存分叉、叠加病变、正向/负向/命名永久微调、走遍四地、重复单一路线、收集三件遗物、十次返航和正负同舱。

遗物和成就只增加收藏记录，不提供战力、分数、Token 奖励、额外远征机会或稀有度加成。

## 档案与隐私

远征区块在 schema v14 引入，并在当前 schema v15 中保持不变；它只保存稳定的目的地、事件、选择、变化、遗物、成就、状态、序号、阅历日、日期字段，以及本地派生计划哈希。它不会保存 Prompt、回复、路径、模型名、精确 Token、请求数或逐请求时间。

schema v13 迁移后只会得到空远征历史，不会虚构过去的远征或发现。第一次持久化迁移仍会保留精确本地备份；写入继续使用与其他异变体动作相同的原子锁和乐观并发校验。
