# 污染实验室

[English](./laboratory.md)

污染实验室会把已有派生收藏变成一套纯本地的选择与陈列玩法。它不读取 Agent 原始日志，不消耗原料，也不奖励更多 Token 消耗。

## 命令

```bash
anti-ai lab
anti-ai lab --json

anti-ai lab incubate <1|2|3>
anti-ai lab incubate <1|2|3> --json

anti-ai lab shelf
anti-ai lab shelf --full
anti-ai lab shelf --json

anti-ai lab inspect <培养物编号>
anti-ai lab inspect <培养物编号> --json

anti-ai share --card culture
anti-ai share --card culture --id <培养物编号>
```

可运行 `anti-ai help lab`、`anti-ai help lab incubate`、`anti-ai help lab shelf` 或 `anti-ai help lab inspect` 查看分级帮助。

## 派生原料

实验室只接受已经存在于本地异变体档案中的三类原料：

- 显式执行 `encounter --save` 后保存的外来标本；
- 每 90 个阅历日世代封存的永久化石；
- 执行 `creature intervene <1|2|3>` 后形成的病例切片。

原料只是引用。培养不会删除或消耗标本、化石和病例切片。只有一类原料时，配方会把它与本体组织组合；有两类时，从两类中各取一份；三类齐全时，两组配方使用跨类别双原料，第三组同时使用三类原料。

没有原料就不会出现配方。实验室会提示可生成派生原料的命令，不会把空培养皿包装成每日任务。

## 稳定配方批次

每个批次包含三组配方。配方 ID、原料选择、培养类型、生态、病灶、并发症、副作用、稀有度和 ASCII 外观都由以下信息派生：

```text
本地异变体 seed + 实验室批次 + 配方槽位 + 排序后的原料 ID
```

所选日期、语言、终端宽度、重复查看和当前 Token 总量都不能重抽批次。执行 `incubate 1`、`2` 或 `3` 会封存对应结果并推进本地批次，另外两组配方不会保存。

这里没有网络随机数、倒计时、每日免费次数、断签惩罚或付费重抽。

## 培养结果

首版会组合：

- 6 种培养类型；
- 3 种生态方向；
- 4 种病灶；
- 6 种并发症；
- 6 种副作用；
- 一份确定性培养皿 ASCII 和 12 字符外观指纹。

稀有度取决于原料类别多样性和一次确定性的本地散列分支：

| 原料多样性 | 结果 |
|---|---|
| 三类派生原料 | 史诗，约 7% 分支为神话 |
| 两类派生原料 | 稀有，12.5% 分支为史诗 |
| 一类派生原料 + 本体组织 | 普通、罕见或稀有 |

这些比例描述固定散列区间，不是在线概率服务。Token 量、异变体能力、恶性阶和重复执行命令都不能改善结果。

## 培养架、图鉴与卡片

`lab shelf` 默认展示最近六份培养物；`--full` 展示完整本地培养架，JSON 始终返回完整机器可读列表。`lab inspect` 会展示单个培养物的原料、培养皿 ASCII、诊断、并发症和副作用。

已封存培养物也会进入 `anti-ai codex`，记录稳定 ID、类型、稀有度、发现日期、原料类别和外观指纹。它们不会改变固定 50 项图鉴的分母。

`share --card culture` 会把最近一份培养物输出为 1200×630 SVG；`--id` 可指定其他培养物。SVG 只写入标准输出，不会上传。

## 成长护栏

培养物不会改变：

- 阅历日和生命阶段；
- 污染性、清醒性、病灶或主异变体外观；
- 普通能力、恶性阶、天赋或异色能力；
- 成就进度、进化概率或病例间隔；
- 战力、分数、Token 收益或资源估算。

实验室是一套收藏与叙事系统。多烧 Token 不是捷径；外来交换、中性阅历日、显式病例选择和已有本地历史提供彼此独立的原料路线。

## 档案与隐私

异变体档案使用 schema v9。`laboratory` 只保存：

- 实验室格式版本和下一批次；
- 稳定培养物与原料 ID；
- 封存日期和批次；
- 离散培养类型、生态、病灶、并发症、副作用和稀有度 ID；
- 派生 ASCII 行和外观指纹。

schema v1–v8 会在本地幂等迁移，只新增空实验室，不会虚构历史实验。

状态、JSON、图鉴和培养物卡片都不会包含精确 Token、请求数、模型与 Agent 名、Prompt、回复、工具调用、本地路径、个人基线或逐请求时间。所有内容仍保存在 `~/.anti-ai/creature.json`。
