# 本地访客共处

[English](./visitors.md)

访客共处在现有 AA1 遭遇流程上增加一层轻量、无服务器的关系展示。已保存的外来标本可以进入本地生态舱，按自然日派生确定性的共处诊断、短讯和共同展品，再被送离；整个过程不会改变任何一只生物的成长。

## 使用流程

先保存一次现有 AA1 遭遇：

```bash
anti-ai encounter <污染编码> --save
```

再查看和管理本地访客档案：

```bash
anti-ai encounter visitors
anti-ai encounter visitors --json
anti-ai encounter host <外来标本编号>
anti-ai encounter release
```

可运行 `anti-ai help encounter visitors`、`anti-ai help encounter host` 或 `anti-ai help encounter release` 查看分级帮助。所有命令都支持 `--date YYYY-MM-DD`；人类输出支持 `--lang zh|en`，JSON 不受语言影响。

在 `anti-ai tui` 中进入第 `2` 区“生态舱”，然后按 `v`：

1. 按 `i`，粘贴一份 `AA1...` 污染编码；
2. 按 `Enter` 校验并预览接触事故，预览保持只读；
3. 按 `Enter` 或 `y` 明确确认，只保存派生的外来标本记录；
4. 选择已归档访客并按 `Enter` 使其入住；按 `x` 送离当前访客。

TUI 最多接收 2,048 个字符。超长、畸形、不支持版本、校验失败、自身编码或非法载荷都会安全失败，并且不写状态。访客接待台打开时，背景动态会暂停。

## 共处模型

同一时刻最多只有一位访客。重复接待当前访客是幂等的；接待另一位访客会在所选日期关闭上一段共处，再开启新记录。重复送离同样不会制造额外记录。

历史生态舱根据入住/送离日期判断当时的访客，而不是直接读取今天的活动指针，因此过去日期仍能显示当时正在共处的标本。日期回拨不能改写一段在未来才开始的共处。

当前共处按自然日进入三个阶段：

| 阶段 | 自然日 | 含义 |
|---|---:|---|
| 入舱 | 1–2 | 初次隔离与互相怀疑 |
| 稳定 | 3–6 | 共处症状开始固定 |
| 常驻 | 7+ | 长期行政性污染 |

这里没有打卡、访客货币、漏日惩罚、好感度或累积机会。

## 共享生态舱投影

本体生态和访客生态会选择污染、清醒、悖论三条平衡路线之一。每条路线各有 4 种关系诊断、4 条访客短讯和 4 件共同展品。结果只由稳定本地 ID、双方外观指纹、共处记录、阶段和所选日期确定。

终端 `creature habitat`、稳定 Habitat JSON、TUI 和 `share --card habitat` 共用同一份投影。重复进入、调整终端宽度、切换语言或增加 Token，都不能重抽同一天的诊断、短讯或展品。

访客可以与已经绑定的伴生物同时存在。访客共处不会替换、喂养、加速或修改伴生物成长。

## 状态与隐私

异变体 schema v16 新增版本化 `visitation` 记录，只包含：

- 一个可为空的当前共处编号；
- 稳定的共处编号与外来标本编号；
- 入住日期与可为空的送离日期。

已保存外来标本仍沿用原有隐私安全的遭遇和混种外观快照，污染编码本身永远不会写入档案。访客状态不包含精确 Token、请求数、来源/模型名、Prompt、回复、工具调用、路径、逐请求时间、联系方式、账号标识、消息或远端身份声明。

AA1 校验值只能发现损坏，不能充当签名。污染编码既不能证明所有权，也不能证明作者身份；应把它视为公开且不可信的收藏品。校验、保存、共处和展示全部在本地完成，没有服务器、上传、账号、聊天、好友列表、发现服务、遥测或后台监听。

访客接待、入住和送离不会增加阅历、能力、生态、稀有率、收藏概率、伴生印记、远征机会、分数、战力或 Token 奖励。
